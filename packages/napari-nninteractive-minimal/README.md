# napari-nninteractive-minimal

This package is retained as an internal compatibility component for existing
ARTIST studies. It no longer registers a standalone napari plugin. For the
lasso-only workflow use **nnInteractive (BEACON 3-plane Lasso)** from
`napari-nninteractive-beacon`.

A minimal version of [napari-nninteractive](https://github.com/MIC-DKFZ/napari-nninteractive).
